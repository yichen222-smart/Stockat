# Stockat 股小喵｜用户指南

版本：1.0｜适用范围：上海、深圳普通 A 股｜自动早报：A 股交易日 08:30 起

> 这是一套新闻整理和网格参数辅助工具。它不会连接证券账户，不会自动下单，也不承诺收益。

## 1. 你能用它做什么

- 每个 A 股交易日早上收到与你关注内容有关的盘前信息；
- 关注自己感兴趣的板块和股票；
- 为指定股票计算网格参考参数和停止条件；
- 手动记录实际发生的网格买入、卖出档数；
- 随时暂停早报或临时生成自己的报告；
- 每个人的数据彼此隔离，只能看到自己的关注、记录和报告。

## 2. 第一次使用

新用户通过管理员邀请加入后，会收到欢迎消息。按下面两步初始化：

1. 添加关注板块，例如：`添加板块：银行`
2. 添加股票，例如：`添加股票：600519`

如果还需要网格参数，发送：`添加网格股票：600036`

最后发送：`查看我的关注`，确认设置正确。早报默认开启。

## 3. 常用指令

### 3.1 板块关注

| 你想做什么 | 发送内容 | 结果 |
|---|---|---|
| 查看全部关注 | `查看我的关注` | 显示自己的板块和股票 |
| 添加板块 | `添加板块：半导体` | 加入板块新闻跟踪 |
| 暂停板块 | `暂停板块：半导体` | 暂时不跟踪，保留设置 |
| 恢复板块 | `恢复板块：半导体` | 重新开始跟踪 |
| 删除板块 | `删除板块：半导体` | 从当前关注中移除 |

板块名称最长 20 个字符，可以使用中文、英文、数字、下划线和短横线。

### 3.2 股票关注

| 你想做什么 | 发送内容 | 结果 |
|---|---|---|
| 添加普通股票 | `添加股票：600519` | 关注相关新闻，不计算网格 |
| 添加网格股票 | `添加网格股票：600036` | 关注新闻，并计算网格参数 |
| 暂停股票新闻 | `暂停股票新闻：600519` | 保留股票，但不推送相关新闻 |
| 恢复股票新闻 | `恢复股票新闻：600519` | 重新推送相关新闻 |
| 停止网格跟踪 | `停止跟踪网格：600036` | 关闭网格，股票仍保留在关注中 |
| 删除股票 | `删除股票：600519` | 同时移出关注和网格跟踪 |

股票既可以输入 6 位代码，也可以输入名称。名称存在多个近似结果时，机器人会提示确认。

### 3.3 “添加股票”和“添加网格股票”的边界

| 功能 | 普通股票 | 网格股票 |
|---|---:|---:|
| 出现在“我的关注” | 是 | 是 |
| 提供相关新闻 | 是 | 是 |
| 计算网格参考参数 | 否 | 是 |
| 可以记录买卖档数 | 否 | 是 |
| 检查停止条件 | 否 | 是 |

网格股票包含普通关注股票的功能，并额外启用网格计算和成交记录。普通股票可通过再次发送“添加网格股票”升级；再次发送“添加股票”不会取消已有网格功能。

### 3.4 查看网格

| 你想做什么 | 发送内容 |
|---|---|
| 查看全部网格股票 | `查看我的网格` |
| 查看指定股票 | `查看 600036 网格` |

你会看到参考价、买卖档间距、正常范围、极限停止价、当前状态和数据截止日期。参数来自历史前复权行情，不是未来价格预测。

### 3.5 记录实际成交

机器人不会读取你的证券账户。只有实际成交后主动告诉它，记录才会更新。

- 买入一档：`记录买入：600036`
- 卖出一档：`记录卖出：600036`
- 一次记录两档：`记录卖出：600036 2`
- 自然说法：`我今天在 600036 买入一档`
- 输错后撤销：`撤销上一条网格成交记录`

系统保存方向、档数和时间。连续同方向记录会累计；反方向成交会把上一方向的连续计数归零。连续同方向达到 5 档时，系统把该网格标记为停止。早报展示连续档数汇总，不展示完整逐笔流水。

只记录真实发生的成交，不要把计划委托当作成交记录。

### 3.6 管理早报

| 你想做什么 | 发送内容 |
|---|---|
| 暂停自动早报 | `暂停早报` |
| 恢复自动早报 | `恢复早报` |
| 临时查看报告 | `立即生成我的报告` |

临时生成报告不会替你下单，也不会修改第二天的关注设置。

## 4. 每天会收到什么

系统按三个固定栏目生成消息：

1. 盘前提示：当天重要市场信息；
2. 你的关注：板块新闻和股票新闻分开显示；
3. 网格参数：最近收盘价、参考价、买卖档间距、运行范围、停止价和你的连续成交记录。

微信平台单条消息存在约 2000 字的技术上限。关注内容较多时，一个栏目可能被平台继续拆分，但栏目顺序不会改变。

报告会标明新闻和行情的截止时间。非 A 股交易日通常不自动发送。

## 5. 网格什么时候会停止

满足任一条件时，系统会将整套网格标记为停止：

- 连续买入 5 档或连续卖出 5 档；
- 收盘价连续两个交易日位于正常范围同一侧之外；
- 单日收盘价越过任一极限停止价；
- 出现重大风险公告、停牌、ST 或退市风险；
- 行情或指标数据异常，无法可靠计算。

看到“停止”后，不要继续沿用旧参数。先核对原因，等待系统重新评估或联系管理员检查数据源。

## 6. 常见问题

### 没收到早报

先发送 `查看我的关注`，确认自己仍有关注内容；再确认没有发送过 `暂停早报`。若仍未收到，请告诉管理员，不要反复添加同一股票。

### 股价和手机行情不一致

先比较数据日期和复权口径。网格计算使用前复权日线；报告中的“最近收盘价”会标明对应交易日。盘中实时价格与上一交易日收盘价不同是正常现象。

### 指令没有识别

使用本指南中的完整格式，尤其保留冒号和 6 位股票代码。例如：`添加股票：600519`。

### 可以自动交易吗

不可以。本系统不接券商、不读取持仓、不代客操作。所有成交都由用户自行决定并在证券账户中完成。

## 7. 使用原则

- 新闻摘要可能受数据源时效影响，重要信息请回到公告或官方来源核对；
- 网格参数是基于历史数据的条件化参考，不代表未来收益；
- 系统不知道你的资金规模、仓位和风险承受能力；
- 不要向机器人发送券商密码、验证码、API Key 或服务器密码；
- 所有内容仅作信息整理和参数参考，不构成投资建议。
